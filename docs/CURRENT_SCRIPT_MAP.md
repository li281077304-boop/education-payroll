# 当前脚本地图

状态含义：`当前使用` 表示当前 Skill 明确提供或 8 月最终流程实际调用；`可能使用` 表示存在调用证据但没有独立运行日志；`旧版` 表示历史资产；`无法判断` 表示不能从文件证据确定正式入口。

## 当前工资 Skill 内脚本

### `_grade_extractor.py`

原始位置：`~/.workbuddy/skills/工资核对表制作/scripts/_grade_extractor.py`

当前状态：当前使用（辅助模块）。

输入：班级名称、可选的上课科目、教学形式，以及 Skill 包内年级查表。

输出：年级、学科、班型标准化结果；F/G/H 的 SWITCH 公式字符串。

主要功能：班型映射、初一/初二/初三归一、衔接班和领航规则、特殊班级查表。

被谁调用：`import_paikeshi.py`；8 月 `build_8月核对表.py` 通过 `sys.path` 导入。

是否会修改 Excel：否。

是否依赖其他文件：依赖 `references/学生年级查表.csv`；当前归档中因包含真实学生信息而未提交。

与其他版本关系：是当前 Skill 的共享辅助模块，不等于 8 月最终年级人工定级逻辑；8 月早期生成脚本另加了 `grade_recede`。

### `import_paikeshi.py`

原始位置：`~/.workbuddy/skills/工资核对表制作/scripts/import_paikeshi.py`

当前状态：当前使用（通用生成入口；未证明为 8 月最终入口）。

输入：排课 xls/xlsx、工资核对表模板。

输出：带 `排课记录` 页的工资核对表；写入 A–H、清理多余行、设置重新计算。

主要功能：兼容旧/新列名；过滤 `已上课` 且 `实到>0`；调用 `_grade_extractor`；报告未知年级。

被谁调用：由 Skill 命令行示例直接调用；没有自动调用其他工资脚本。

是否会修改 Excel：会写入指定输出文件，并默认先生成 `.bak`。

是否依赖其他文件：模板、`_grade_extractor.py`、其年级查表。

与其他版本关系：与 8 月专用生成脚本功能重叠，但 8 月专用脚本多了填报数据隐藏页、工资核对公式和 8 月回调逻辑。

### `verify_ae_af.py`

原始位置：`~/.workbuddy/skills/工资核对表制作/scripts/verify_ae_af.py`

当前状态：当前使用（只读检查）。

输入：薪资表 xlsx；可选星级覆盖 CSV；可选跳过关键词。

输出：AE 不匹配清单、AF 不匹配清单和统计；不写回文件。

主要功能：根据 AD 档位、F 星级、TRMT 规则计算期望 AE/AF。

被谁调用：由 Skill 命令行示例直接调用；不调用 `import_paikeshi.py`。

是否会修改 Excel：否。

是否依赖其他文件：只在提供 `--star-override` 时依赖 CSV；Excel 本身提供 AD/AE/AF/F。

与其他版本关系：它是当前 Skill 的 AE/AF 规则程序化部分，不覆盖续费、退费、管理绩效和全盘复查。

原始位置：`/Users/macos/Desktop/8月工资表/build_8月核对表.py`

是否依赖其他文件：固定绝对路径；依赖当前 Skill 脚本、模板、理化薪资表。

## 管理考核脚本

### `compute_kh_metrics.py`

原始位置：`~/.workbuddy/skills/管理岗位考核/scripts/compute_kh_metrics.py`

当前状态：可能使用。

输入：数学/理化统计表、续费表、退费表、月份和目录。

输出：打印一对一月周均、续推人次、退费人次，并打印学生页供人工取总学员数。

主要功能：读取 `组课时生产` 月总行 K 列；统计续费表周列非零单元格；统计退费表扣款教师列非空记录；学生总数不自动决策。

被谁调用：Skill 命令行直接运行；不写薪资表。

是否会修改 Excel：否。

是否依赖其他文件：依赖真实统计/续费/退费工作簿和准确 sheet 名。

与其他版本关系：管理岗位考核独立于工资底稿，当前没有被工资主流程统一编排。

## 结论

当前没有一个“正式入口脚本”串起整个工资流程。最接近的程序链是：排课生成脚本 → Excel 公式核对 → AE/AF 只读检查 → 续费解析/管理指标辅助 → 人工合并与复查。最终采用哪个备份、何时确认和哪些人工值进入总表，仍无法完全从脚本反推出。
