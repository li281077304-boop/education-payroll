## 解释

这次干跑验证的是“真实 Excel → 标准对象 → 对账引擎”链路能否工作，不是对工资正确性的背书。两项未解释差异和两项人工复核项均被引擎显式保留，未出现“无差异即通过”的错误结论。由于 Coverage 不是 100%，且仍有未解释差异，系统按门禁规则拒绝 PASS。

本次 CLI 不输出人员、来源单元格或金额；需要追溯时，开发者可在本机内存中通过 `SourceEvidence` 查看来源文件、Sheet、坐标、源字段、原始值状态和标准化值，而这些证据不写入 Git。

## 公式与外部引用

本次用于一对一计算的字段在两份工资表中可读。最终核对工作簿另有公式缓存和外部引用限制，详见 [AUGUST_FILE_MAP.md](AUGUST_FILE_MAP.md)：这些单元格不会被解释为数值 0，也没有用于宣布干跑通过。

## 未映射边界

- 当前只实现一对一的窄范围期望值重算：标准化排课的实到人数 × 2 小时 × 已识别年级系数。
- 续费、退费、管理岗位考核、批注的业务含义尚未纳入最终计算。
- 公式外链目标缺失时只能报告 `EXTERNAL_REFERENCE_UNRESOLVED` 类风险，不能重算。
- 无直接年级标记或无实到人数的排课，不能参与一对一期望值计算，必须进入人工复核。
