## 本轮真实只读复核（脱敏）

- 当前 2026-08 本组样本中，所有实到为 0 的记录均进入“不适用”，没有形成 UNKNOWN。
- 原先缺年级的本组课程均为赠送／换购／特批命名模式；本地 Skill 既有学生年级权威表可全部补齐。
- 课程名称明确标记 1v2 的泛称“一对多”记录可稳定识别为 1对2；没有明确标记的泛称不会被猜测为 1对2。
- 加入上述权威年级查表与班型识别后，本组逐课结果没有 UNKNOWN contribution；实到为 0 的记录不参与合计。
- 当前提交工资表的 AA / AD 目标列存在公式缓存缺失，不能作为可靠数值比较目标；这是工资表可读性问题，不是 Core 将其当作计算输入。
- 剩余 AC 差异保留为逐课可追溯的业务差异，不以调整公式或总数方式“对平”。
