## 分类依据与边界

- **CURRENT**：当前最终版本或本期正在使用的工资填报/核对工作簿。
- **INPUT**：被当前 Skill、脚本或文件关系明确指向的外部事实来源；不是“已被新 Core 全量支持”的含义。
- **INTERMEDIATE**：用于生成或修正中间核对结果的文件。
- **BACKUP**：文件名和修改时间显示为同一工作簿的显式历史备份，全部保留在原处。
- **UNKNOWN**：仅凭结构和文件关系无法可靠判定，未用推测补全。

## 发现的布局

1. `SCHEDULE_EXPORT_V1`：原始排课导出。标题行可识别班级、教学形式、上课时间、上课状态、实到、上课学员、上课科目、任课老师。
2. `PAYROLL_SHEET_V1`：两份学科工资表。通过“姓名、最终授课小时数据、该档每小时金额、总课时费、总工资数”组合识别，而非固定列号；当前样本的业务字段可追溯到 AA/AC/AE/AF/AV。
3. `PAYROLL_CHECK_V1`：最终核对工作簿。包含“排课记录”“工资核对”和隐藏“填报数据”页；工资核对页的语义序列为 `1对1 → 填报 → 差值 → 班课 → 填报 → 差值`。
4. `RENEWAL_2026_V1`：续费表布局已识别但本阶段未实现读取 Adapter。

最终核对工作簿中的公式缓存不可可靠读取：结构扫描发现其排课记录、工资核对、隐藏填报数据三页合计 **8,165** 个公式单元格缺少可读缓存，其中隐藏填报页有 **56** 个外部引用公式。Adapter 不会把这些值当作 0；其状态须保留为 `MISSING_CACHE` 或 `EXTERNAL_REFERENCE`。
