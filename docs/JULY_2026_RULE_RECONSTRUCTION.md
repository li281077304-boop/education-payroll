## 已确认的 July Core 规则

July 的规则版本为 `core_rules_2026_07_v1`，仅覆盖 `2026-07`，存放于 `config/core_rules_2026_07.yaml`。它是独立快照，不复用 August Run 的人工确认、状态或后续版本。

### AA / AC / AD

- 每节课按 2 小时折算。
- 一对一：`实到人数 × 2 × 年级系数`，汇总为 AA。
- 普通小班：`年级系数 × 实到人数系数 × 2`，实到人数系数 1～10 人依次为 `0.8、1.0、1.2、1.4、1.7、1.9、2.1、2.3、2.5、2.7`。
- July 核对表的特殊班型证据明确出现 `1对2`：1 人 `0.8`、2 人 `1.2`；未出现在 July 证据中的特殊班型不被自动套用。
- 年级系数：一年级至六年级 `0.85`，七至八年级 `0.9`，九年级 `1.0`，高一 `1.1`，高二 `1.25`，高三 `1.35`，雅思/托福 `1.5`。
- `AD = AA + AC`。排课状态不是“已上课”或实到不大于 0 的记录不计入；未知事实保持待确认，不转成 0。

### AE / AF

- AE 使用独立档位规则和星级证据；July 工资表的 F 列只作为提交资料参考，不能反向改变 AA/AC/AD。
- AF 遵循教师个人工资政策；普通全职默认义务课时只是候选，必须由 Run 级确认或个人政策证据确定。历史工资表中明确记录的按节单价只进入 July 历史对账分类，不自动变成 August 的生产政策。

### 模板与导出

- M 公式：`(G + H + I + J) / K × L`。
- AA 公式使用年级输入列、每节 2 小时和上述年级系数；AD 使用 `AA + AC`；AF 使用 `MAX(0, (AD - 义务课时) × AE)` 或教师政策指定的等价规则；AV 汇总模板的直接组成项。
- 导出始终创建新文件并重新打开校验；原始工资表、核对表和排课表不写回。

## 差异分类契约

July 历史对账对每位可比教师逐字段比较 `AA、AC、AD、AE、AF`。每一个不一致字段都独立写入 `difference_category` 和证据，不以教师姓名、Golden 数值或总差额硬编码：

| 字段 | 主要证据 | 分类 |
|---|---|---|
| AA | 一对一逐课贡献、日期、课程来源位置 | `COURSE_CONTRIBUTION` |
| AC | 普通/特殊班逐课贡献、实到人数、系数和课程来源位置 | `COURSE_CONTRIBUTION` |
| AD | 同时汇总 AA 与 AC 的逐课贡献 | `COURSE_CONTRIBUTION` |
| AE | 生效期、档位边界、独立星级权威和工资表值 | `RULE_DIFFERENCE` 或明确的资料/权威缺失分类 |
| AF | AD/AE/义务课时公式、个人政策或历史按节单价批注 | `COURSE_CONTRIBUTION`、`PERSONAL_EXCEPTION`、`PART_TIME_RATE`、`MISSING_SOURCE` 或 `RULE_DIFFERENCE` |

分类只由读取到的字段、公式、政策和逐课证据决定；没有证据时保留异常，不能为通过而改写历史值。

历史值或当前值在 AA、AC、AD、AE、AF 任一字段单侧缺失时，仍生成该字段的 `NEEDS_CONFIRMATION` 记录并分类为 `MISSING_SOURCE`，明确缺失侧；不会把空值当作 0。即使有贡献对象，只有同时匹配教师、字段和排课来源记录时才可使用 `COURSE_CONTRIBUTION`，空贡献或未匹配来源仍按缺失证据处理。
