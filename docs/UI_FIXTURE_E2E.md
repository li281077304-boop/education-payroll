# UI V1 脱敏端到端验收

本次验收仅使用 `tests/fixtures/excel/` 的人工构造工作簿和临时本地记录，不读取真实工资工作区。

| 场景 | 预期结果 | 自动验证 |
|---|---|---|
| AA、AC 正常 | 两项均显示“已核对”；整份工资仍为需要复核 | 是 |
| AA 差额 | 显示原始排课值、工资表值、差额和两端来源位置 | 是 |
| AC 差额 | 作为需要处理的问题出现 | 是 |
| 人工特殊情况 | 意见持久保存，重新核对后成为已确认差异，不强制通过 | 是 |
| 原始文件变化 | 核算变为“文件已变化”，查看证据被阻止；重新导入后可重新核对 | 是 |
| 程序关闭后恢复 | 本地记录和人工意见仍可读取 | 是 |
| 两张工资表教师重复 | 核对失败但回到“材料已准备”，错误可见且可恢复 | 是 |

验收重点：AA/AC 的核对来自单独导入的原始排课，不使用最终工资表或加工后的检查表为自身背书；AE/AF/AV 不会被显示为自动通过。
