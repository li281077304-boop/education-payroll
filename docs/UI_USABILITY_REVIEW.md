# 工资核算助手 V0.1 易用性复核

复核对象是完全脱敏的 Excel fixture 和本地界面；没有读取真实工资文件。

## 管理人员能完成的流程

新建月份 → 依次选择三份材料 → 看清每份材料的识别与风险 → 开始核对 → 在异常中心看系统值、工资表值、差额和来源 → 记录人工意见 → 重新核对 → 导出报告。

界面不要求理解 Python、配置文件、布局识别或核对引擎。技术信息只放在“查看文件信息”和问题来源中，且翻译为来源文件、工作表、位置。

## 本轮简化

- 原先分散的“最终复查”并入“核对结果”：重新核对永远检查全部材料。
- 原先五个工作页收敛为四个：材料准备、核对结果、待处理问题、管理岗位确认。
- 材料卡片改为业务名称和单独按钮，不让用户猜一个文件对应什么用途。
- AA/AC/AE/AF/AV 用“读取、原始依据、重新计算、比较”展示真实范围，避免把读取误说成核对。
- 异常列表默认按严重程度排列，并提供项目、处理状态、意见和教师筛选。
- 文件变化使用醒目提示，并明确说明旧结果不再有效。

## 当前仍然别扭的五处

1. 导入仍依赖系统文件选择窗口，尚未提供稳定的拖拽导入。
2. AE/AF 的每人公式提醒在教师很多时会让问题列表显得拥挤；这是范围不完整的真实反映，不应隐藏。
3. 管理岗位确认目前没有可靠自动参考值，只能明确地留给人工填写。
4. 当前是本地 Python 启动方式，尚未打包为双击可安装应用。
5. 课程来源明细没有分页；排课很多的教师展开后会较长。

这些都是体验上的限制，不是通过伪造自动结论来掩盖的理由。
