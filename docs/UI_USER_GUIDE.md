# 工资核算助手 V0.1：使用方式

1. 新建一个核算月份。
2. 分别导入原始排课数据、数学组工资表、理化组工资表；最终工资核对表可选。
3. 在“材料导入”确认文件已识别后，点击“开始核对”。
4. 在“核对总览”看每一项的真实范围。只有同时拥有独立权威源、独立计算和工资表比较，才会显示“已核对”。
5. 对问题打开“查看明细”，查看来源文件、工作表和单元格证据；必要时记录人工处理意见。
6. 点击“重新全盘复查”。最终状态始终由 Payroll Core 重新计算，界面不能自行改成通过。

当前版本能独立核对 AA（一对一）与 AC（班课）。AE、AF 只能公式复算，AV 仅只读展示；它们没有完整独立权威数据链，因此整份工资核对不会被显示为通过。
