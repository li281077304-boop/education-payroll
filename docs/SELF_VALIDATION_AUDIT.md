# 工资表自证风险审查

本审查只报告风险，不把未确认业务规则扩展成新功能。

| 字段/环节 | 当前风险 | 本阶段状态 |
|---|---|---|
| F 教师级别 / 星级 | 工资表自身提供星级再用于复算 AE，会掩盖错星级。 | 已由独立星级版本防守。 |
| AE 该档每小时金额 | 若以工资表 F、AD 复算，仍可能自证。 | 已使用独立星级与版本化金额规则核验。 |
| AF 总课时费 | 公式正确不代表 AD/AE 输入正确。 | AE 已独立检查；AF 仍需要独立身份/TRMT 权威来源。 |
| AV 总工资 | 汇总续费、退费、激励、管理项，当前多数来源尚未接入。 | 明确仅读取，不可完整通过。 |
| 管理岗位考核 | 最终数值包含主观认定。 | 保持人工最终确认，不由系统反推。 |

本次发现 5 个潜在自证风险，其中星级和 AE 已新增独立防线；AF、AV、管理考核仍待各自权威来源接入。
