# 工资核算助手 V0.1 规格

## 面向用户的流程

1. 在首页新建一个工资月份；历史记录按最近操作时间排列。
2. 在“材料准备”中分别选择原始排课数据、数学组工资表、理化组工资表。
3. 工具说明每份材料是否已识别、是否可读取，以及公式或外部文件带来的风险。
4. 点击“开始核对”，由本机工资核对核心重新读取三份材料并完成比较。
5. 在“核对结果”查看每个工资项目实际检查到了哪一步；在“待处理问题”筛选、查看来源和记录人工意见。
6. 点击“重新核对全部材料”。结果只能由核对核心重新计算，界面不能自行改成通过。
7. 按需导出字段级核对报告。导出不修改任何导入的 Excel。

## 页面结构

首页只放最近核算、新建核算和下一步动作。进入一个核算后，界面收敛为四个页面：

- 材料准备：三份必需材料、材料提示和开始核对。
- 核对结果：排课项目完成度、AA/AC/AE/AF/AV 的实际核对范围、重新核对和报告导出。
- 待处理问题：按严重程度排序，可按项目、处理状态、是否已记录意见和教师筛选；详情显示来源文件、工作表和单元格。
- 管理岗位确认：只保存人工最终确认值与确认人。没有可靠自动数据时明确显示“暂无可靠自动数据”。

## 项目核对范围

| 项目 | 当前界面结论 | 依据 |
|---|---|---|
| AA 一对一折算小时 | 可独立核对 | 原始排课数据独立计算后与工资表比较。 |
| AC 班课折算小时 | 可独立核对 | 原始排课数据独立计算后与工资表比较。 |
| AE 该档每小时金额 | 公式复算 / 待权威确认 | 可按现有工资表公式复算，但决定金额的上游依据尚未接入。 |
| AF 总课时费 | 公式复算 / 待权威确认 | 可按现有工资表公式复算，但上游依据尚未独立接入。 |
| AV 总工资 | 仅读取 / 待人工确认 | 包含尚未接入的续费、退费、激励和管理项。 |

因此，V0.1 不把“字段读取成功”称为“已核对”，也不提供整份工资的自动通过结论。AA/AC 的独立范围完成，只表示这两个项目已核对。

## 人工处理与文件变化

对问题可记录：特殊情况、工资表待修改、暂时保留、来源待核实。处理意见只保存为本地记录，不会写回 Excel；保存后仍须重新核对。

每份材料保存 SHA-256、大小和修改时间。原文件被替换、移动或由 WPS 改写后，核算变为“文件已变化”，旧结果和人工意见不再有效，必须重新导入并重新核对。

## 语言与错误提示

普通页面使用“材料准备”“原始排课”“工资表”“核对完成度”等业务语言。文件解析和布局识别等技术细节默认隐藏。文件打不开、格式不支持、公式结果无法读取、外部文件未解析、检查范围不完整都会给出可行动的中文提示。
