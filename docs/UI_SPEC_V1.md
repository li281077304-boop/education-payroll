# 工资核算助手 V0.1 规格

首页显示最近核算与“新建工资核算”。每个 run 有五个页面：材料导入、核对总览、待处理问题、管理岗位考核、最终复查。

材料按业务名显示：原始排课数据、数学组工资表、理化组工资表为自动核对必需材料；最终工资核对表为辅助证据；续费与退费表保留“暂未接入”。导入后显示识别结果、记录数、教师数、公式/外链风险和文件版本。

核对总览按 AA、AC、AE、AF、AV 分别显示四段状态：已读取、独立权威源、独立计算、已与工资表比较。AA/AC 只有原始排课独立计算并与工资表比较成功才是已核对。AE/AF 当前是公式复算，AV 仅读取，页面必须写明待人工确认。

问题详情显示系统值、工资表值、差值及来源文件、Sheet、单元格。人工操作只记录事实：特殊情况、工资表需修改、暂缓、确认来源；保存后必须重新全盘复查。管理岗位页只显示系统参考值与人工最终确认值，当前没有可靠自动数据的字段显示“暂无可靠自动数据”。

最终页的状态由 Payroll Core 的结果及字段范围门禁共同决定。AA/AC 的未解释差异、缺失源、未知年级、文件变更或未处理的来源确认均阻止相应项目显示已核对。因为 AE/AF/AV 尚未有独立权威链路，V1 不提供“完整工资通过”文案，只导出字段级核对报告。
