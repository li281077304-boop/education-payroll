# Payroll Reliability Audit

## 已实现的独立资料

教师星级以本地 SQLite 中的版本记录保存。每条版本含生效开始、结束、来源、版本名与脱敏/真实名单记录。新建工资 Run 时若恰有一条覆盖该月份的版本，Run 保存该版本 id；以后导入新年度名单不改变旧 Run 的绑定。

金额规则来自现有 `ae_tier_rules.md`：AD 分段基础金额加星级加成，规则有效期为 2025-10 至 2026-09。规则以 `CompensationBand` 数据对象表达，多个规则命中会直接报告冲突。

## 公式完整性

公式审计只读打开工资表，定位有“姓名”表头的教师行，并对 AE、AF 的同列公式区域进行相对引用归一化。它能报告固定值覆盖、空白、错误引用、错行、错列和模式中断。公式缓存和外部链接风险继续由 Excel Adapter 单独报告。

## 当前边界

- 未连接真实星级资料前，星级和档位金额都显示待处理，不能完整通过。
- 公式区域少于两个可比较公式时，系统显示待确认而不是假定无异常。
- AF 使用独立教师工资政策档案：身份、有效星级/特批、义务课时、是否扣除、原因和生效期均独立保存。工资表 TRMT 字段仅作交叉检查对象，不能决定 AF 待遇。
- 本阶段未接续费、退费、自动写回或 AI 判断。
