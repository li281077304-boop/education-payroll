# 工资核对表制作流程

从排课记录源文件生成工资核对表.xlsx，含"排课记录"和"工资核对"两个sheet。

> 本 skill 是一个**包**：除本文档外，还包含可直接运行的脚本（`scripts/`）、空白模板（`assets/`）与查表数据（`references/`）。运行环境需 Python 3.9+ 且安装 `pandas` / `openpyxl` / `xlrd`（系统 `/usr/bin/python3` 已具备）。

## 〇、每月原材料清单（开工前先核对齐全）

**A. 用户每月提供的（4 份）：**
1. **排课列表**（xls/xlsx，如 `排课列表_06月29日到08月02日_*.xls`）→ 生成排课记录/核对表/课时生产
2. **两张填报表**：`2026数学组X月薪资表.xlsx` + `2026年X月份理化组薪资.xlsx`（填报课时、星级、批注）
3. **续费+推荐数据**（`2026年度续费+推荐数据(*).xlsx`，含各月续推）→ AH/AI/AJ/AK
4. **退费统计表**（`副本宣城二校退费统计表2026年.xls`，P列=负责教师/Q列=人头/R列=业绩）→ AN

**B. 权威/参考文件（平时备着）：**
5. **5月薪资表**（`2026数学&理化组5月薪资表.xlsx`）→ **星级权威**（数学组提交的星级常错，以它为准）
6. **组长绩效标准**（doc，Documents/06-考核管理/）→ 管理绩效完整规则（用户尚未教完整版）
7. **数据统计表**（数学组/理化组周报表）→ 组课时生产页（月度生产/平均课次）

**C. skill 自带（不用用户提供）：** 工资核对表模板.xlsx、学生年级查表.csv

⚠️ 若某月缺续推/退费/填报表 → 先问用户，不要用空数据硬填。

## 一、脚本用法（核心两步）

### 步骤 A：生成工资核对表
```bash
python3 scripts/import_paikeshi.py \
    --source  排课列表_06月01日到06月28日.xls \
    --template assets/工资核对表模板.xlsx \
    --output  工资核对表6月.xlsx
```
- 自动识别新旧两版列名；过滤"已上课"且"实到>0"；提取年级/学科/班型；写入 F/G/H 的 SWITCH 公式
- 写入前自动备份 `--output`（除非 `--no-backup`）；保存时设 `fullCalcOnLoad` 解决 Excel 打开公式显示 0
- 输出末尾会列出**无法识别年级**的记录，需人工核对或补充 `references/学生年级查表.csv`

### 步骤 B：验算薪资表课时单价
```bash
# 表内 F 列星级可信时：
python3 scripts/verify_ae_af.py --file 2026数学组6月薪资表.xlsx --sheet 工资核对

# 表内星级不可信、以口头确认的星级为准时（如 6 月表）：
python3 scripts/verify_ae_af.py --file 2026数学组6月薪资表.xlsx \
    --sheet 工资核对 --star-override references/star_override_template.csv

# 管理/底薪行不参与课时费规则，跳过：
python3 scripts/verify_ae_af.py --file xxx.xlsx --skip-keywords 管理,底薪
```
- 输出 AE / AF 不匹配清单；**只报告、不修改**，特殊个案（AF 为人工录入值）需人工确认

> ⚠️ 已知：4 月表 28 人中 26 人 AF 完全吻合规则，仅 `任勇`(TRMT，AF 为人工值) 与 `杨宇宸`(AF 人工值) 偏离——属人工录入特例，脚本会标出供复核，勿直接覆盖。



## 一、读取源文件并过滤

- 源文件格式：xls 或 xlsx（OOXML格式），用 `pd.read_excel(..., engine='openpyxl')`
- 过滤规则：
  - 只保留 `上课状态 == '已上课'` 的记录
  - 排除 `实到 == 0`（或列名为"实到人数"）的记录
  - 排除 `实到` 为空的记录
- **注意列名差异**：不同月份的排课记录列名可能不同
  - 旧版本（5月部分）：列名含 `班级名称`、`任课老师`、`课程所属班型`、`课程所属年级`、`实到人数`
  - 新版本（6月以后）：列名含 `上课班级`、`教学形式`、`上课科目`、`任课老师`、`实到`
  - 6月新文件可能多出 `上课科目` 列（直接从系统导出含科目），此时优先使用此列作为学科来源，并清理前缀：`str.replace(r'^\d+-', '', regex=True)`

## 二、列映射规则

| 工资核对表列 | 数据来源 |
|---|---|
| A - 任课老师 | 源文件 `任课老师` 列 |
| B - 年级 | 从班级名称提取（见下方规则） |
| C - 学科 | 优先用 `上课科目` 列��清理数字前缀后），否则从班级名称括号提取 `\((\d+-)?([^)]+)\)` |
| D - 课程所属班型 | 从 `教学形式` 或 `课程所属班型` 映射（见下方） |
| E - 实到人数 | 源文件 `实到` 或 `实到人数` 列 |
| F - 班课绩效 | SWITCH公式 |
| G - 年级系数 | SWITCH公式 |
| H - 人数系数 | SWITCH公式 |
| I - 上课学员 | 源文件 `上课学员` 列（学生姓名，班课多人逗号分隔）——**溯源必备**（2026-09-08 用户要求） |
| J - 上课时间 | 源文件 `上课时间` 列（取 `YYYY-MM-DD HH:MM` 前16位）——**溯源必备** |

> ⚠️ **排课记录必须保留 I/J 溯源列**（2026-09-08 用户要求，踩过坑）：之前只有老师/年级/学科/班型/实到，1v1 差值出现时**无法定位是哪节课/哪个学生**（如"实到0但状态已上课"的课根本查不出——何心 8/12 范梓萱那节）。有学员+时间后可逐节溯源。
> 实现要点：源表过滤（已上课 且 实到>0）后**行序必须与核对表一致（不排序）**才能按行号回填 I/J；回填前先抽查比对（老师+实到）确认行序一致，再整列回填；班课学员多人用逗号分隔、时间取前16位。

### 班型映射
- `一对一` → `1对1`
- `集体班` → `小班`（不论班级名称中是否含"小班"）
- `一对多` → `1对2`
- `10人班`、`6人班`、`8人班` → `小班`

### ⚠️ 班课代课/漏课 → 人工折"一对一价值"计入班课（2026-09-04 用户定案，重要）
**背景**：某老师给别的老师的班（如"小升初11班梁缘"）代课，系统只排了 N 节班课记录，但学生实际只上了 M 次（M < N）。因为一对一不能按班课价收，这类代课**没有标准公式**，折算次数 M 由用户**人为拍板**。

**固定算法（用户口述，须照抄）：**
- 每次一对一的价值 = **1 × 2 × 年级系数**（1 节课 = 2 小时 × 年级系数）
  - 例：六年级（系数 0.85）→ 每次 = 2 × 0.85 = **1.7**
- 总价值 = **人为定的折算次数 M × 每次价值**
  - 例：5 节代课、用户裁定折 3 次 → 3 × 1.7 = **5.1**

**落位规则：**
- 结果**计入班课 AC**（不是 1对1 AA）——用户原话"按一对一的绩效算进班课，他最终还是在班课"
- 实现：直接在薪资表 AC 列写**静态终值**，并在批注里写清拆分：`AC = 系统班课值 + 人工代课值`
  - 例：董葛飞 AC = 45.73（系统班课）+ 5.10（代课 3 次 × 2 × 0.85）= 50.83
- 核对表"填报数据"sheet 的 AC 同步写这个终值；**系统 T 列（SUMIFS班课）会与填报值有差值，属正常**（因为这 5 节在排课记录里仍标 1对1、系数 0，不进系统班课）。用户已确认"只改填报值，不管系统列"。

**注意**：这种代课的折算次数**每次都要问用户**，不要自己套公式猜（因为 M 是人为定的，无标准）。

### 年级提取规则（优先级从高到低）
1. 班级名称含 `领航` → 年级 `领航伴学`
2. 暑假衔接班 → 按**当前在读年级**（2026-07 用户确认）：`小升初`→六年级、`初升高`→九年级、`七升八`→七年级、`八升九`→八年级；**`幼小衔接`→一年级**（2026-08-04 用户确认按一年级计，影响李娜等幼小衔接班课）
3. 班级名称含年级关键词：`一年级`~`六年级`、`七年级`~`九年级`、`初一`~`初三`、`高一`~`高三`；**`初一/初二/初三` 统一归一为 `七年级/八年级/九年级`**（模板表头用七年级系，SWITCH 公式不认初一系）
4. 赠送/换购/特批类 → 从班级名称下划线后提取学生姓名，查 `references/学生年级查表.csv`（已收录 72 名学生，含暑假赠课生）
5. 6月起源文件无 `课程所属年级` 列，全部从班级名称提取

### ⚠️ 换月/跨学期定级：多版本排课表并存时，用"中段导出版"当权威（2026-09 用户定案，重要）
**背景（8月坑）**：月内排课记录可能被导多次（如 8/26 导 + 9/1 导）。**结课班的名字不会动（保持旧年级）**，而**在开的班到下学期会被系统自动升级成新年级名**（如"高二小班化学"→"高三小班化学单周1班"），于是两版表里同名/异名混杂。
- ❌ **禁止"一刀切回调一级"**：曾把 96 组课年级错误降级（其实那批班在 9/1 表里名字没变、年级是对的）
- ✅ **正确规则**：**以中间的导出版（如 8/26 版，= 暑假真实在读年级）为权威基准**，给 9/1 版全量行定级：
  1. 同老师+同上课时间 命中权威版 → 直读权威版年级（覆盖最多）
  2. 同班名 命中权威版 → 直读
  3. 1对1 / 衔接班 / 领航伴学 → 直读（本来就不回调）
  4. 仅 9/1 版有的班：**班名带"单周/双周" = 系统升级的秋季新班 → 回调一级还原**（如"高三小班物理单周2班"→高二）；人名班/无单双周 = 暑假原班 → 直读
- 判定口诀：**系统只升级"在开的班"，结课的班和老师手动建的班名都不动**
- 完成后自查：全表 0 无年级、0 残留异常年级（8月权威版最高只到高二）；被覆盖时可用权威备份按行号恢复 B 列

## 三、SWITCH公式（F/G/H列）

### F列（班课绩效）
```
=_xlfn.SWITCH(B{row},"领航伴学",0.6,"一年级",0.85,...,"高三",1.35,"雅思",1.5,"托福",1.5,0)
*_xlfn.SWITCH(E{row},1,0.8,2,1,3,1.2,4,1.4,5,1.7,6,1.9,7,2.1,8,2.3,9,2.5,10,2.7,0)
*_xlfn.SWITCH(D{row},"小班",1,"1对1",0,"1对2",1.2)
```

### G列（年级系数）
```
=_xlfn.SWITCH(B{row},"领航伴学",0.6,"一年级",0.85,...,"高三",1.35,"雅思",1.5,"托福",1.5,0)
```

### H列（人数系数）
```
=_xlfn.SWITCH(E{row},1,0.8,2,1,3,1.2,4,1.4,5,1.7,6,1.9,7,2.1,8,2.3,9,2.5,10,2.7,0)
```

## 四、工资核对sheet公式

### D-O列（各年级1v1课时 = SUMIFS × 3）
```
=(SUMIFS(排课记录!$E:$E,排课记录!$D:$D,$C$2,排课记录!$A:$A,$C{row},排课记录!$B:$B,{grade_cell}))*3
```
- `$C$2` = "1对1"（班型条件）
- `$C{row}` = 该行教师姓名
- `{grade_cell}` = 对应年级的表头（如 `D$2`="一年级"）

### Q列（折算小时数）
```
=(D{row}+E{row}+...+I{row})/3*2*0.85+(J{row}+K{row})/3*2*0.9+...
```

### R/U列（填报 - **最终方案 = 跨文件动态直连薪资表**，2026-09-08 用户终案）
> ⚠️ 三轮实测结论（全踩过）：
> - 2026-08-04 内嵌隐藏 sheet → 稳定显示，但**静态副本不随薪资表更新**（老师改薪资表→核对表不跳，差值永远核不平）；
> - 2026-09-02 直接跨文件 VLOOKUP → 当时在预览面板看，取不到源表 → 全 #N/A，误以为方案不可行；
> - 2026-09-08 用户明确：**平时用桌面版 WPS/Excel 打开核对表** → 跨文件引用可行（打开时允许"更新链接"/双开源文件即自动刷新）。
> - **最终定案：填报数据 B/C 用跨文件 VLOOKUP 直连薪资表**，薪资表改动 → 桌面版打开核对表自动跳（真动态）。

**做法（最终方案）：**
1. 维护隐藏 sheet "填报数据"，A=姓名；**B/C 写跨文件 VLOOKUP 指向当月合并薪资表**（薪资表 Sheet1：C=姓名、AA(27)=1v1折算、AC(29)=班课折算；区域 `$C$5:$AC$35` 覆盖全部老师）：
   ```
   =VLOOKUP(A{row},'/Users/macos/Desktop/[2026数学&理化组8月薪资表.xlsx]Sheet1'!$C$5:$AC$35,25,0)  # B=1v1 (AA→偏移25)
   =VLOOKUP(A{row},'/Users/macos/Desktop/[2026数学&理化组8月薪资表.xlsx]Sheet1'!$C$5:$AC$35,27,0)  # C=班课 (AC→偏移27)
   ```
   - 列偏移 = 目标列号 − C列号(3) + 1：AA(27)→25、AC(29)→27
   - **路径必须完整绝对路径**（WPS 只认绝对路径；相对 `[文件名]` 会 #N/A）
2. 工资核对 sheet R/U 写内部 VLOOKUP 查填报数据（不变）：
   ```
   =VLOOKUP(C{row},填报数据!$A:$C,2,0)   # R列 1对1填报
   =VLOOKUP(C{row},填报数据!$A:$C,3,0)   # U列 班课填报
   ```
   → 完整链：**R/U → 填报数据 B/C → 合并薪资表 AA/AC**，薪资表改什么核对表跟着跳
3. 保存 `fullCalcOnLoad=True`；交付时提醒用户：桌面版打开核对表**弹"更新链接"要选是/更新**（或先开薪资表再开核对表），预览面板仍会 #N/A（机制限制，非公式错）

**兼职老师（胡涛/刘雨/张祥等）**：不适用 AA/AC 折算规则，薪资表里 AA/AC 为空/0，核对表 VLOOKUP 会取到 0 属正常——兼职单独按节数×单价算（见"五之二 兼职老师"）。

**回退方案（仅当用户以预览为主、无法用桌面版时）**：填报数据 B/C 改存静态值（从薪资表 `data_only=True` 读现值写死），R/U 不变；薪资表被改后"喊 AI 同步"。

### S/V列（差值）
```
=Q{row}-R{row}
=T{row}-U{row}
```

### T列（班课）
```
=SUMIFS(排课记录!F:F,排课记录!A:A,C{row})*2
```

## 五、保存注意事项

### ⚠️ openpyxl 改完后用户再用 WPS 打开保存，会把改动覆盖回旧版（2026-09-03 踩过）
- 现象：AI 用 openpyxl 改完年级列等保存 → 用户随后在 WPS 里打开并 Ctrl+S → **93 行年级被覆盖回"旧一刀切回调版"**（用户可能开的是缓存旧副本/别的窗口）
- 对策：
  1. 改完立刻备份一份"权威版"（如 `.v_权威定级.xlsx`），被覆盖时按行号把 B 列从权威备份恢复
  2. 交付时明确告诉用户：**只认最新这份文件，别拿旧文件覆盖保存**
  3. 二次恢复后要重跑班课 T 校验（恢复前 何心 T=109.4 错、恢复后 =112.7 对）

### fullCalcOnLoad 修复
openpyxl 写入大量公式后，Excel 打开可能不自动重算（公式显示0），需在保存前设置：
```python
wb.calculation.fullCalcOnLoad = True
```

写完新数据后删除多余行：

target_last = len(src) + 1
if ws.max_row > target_last:
    for row in range(ws.max_row, target_last, -1):
        ws.delete_rows(row)

```python
from openpyxl.comments import Comment
# 复制批注（按姓名匹配目标行；已存在的跳过）

### ✅ 批注检查与重写流程（2026-08-07 用户要求固化）
**目的**：老师填报时手写的批注（尤其 AC 列班课明细）**经常与系统排课记录不符**（多记/记错档位），是班课差值对不上的主要根源。核对时**逐人检查批注 → 与排课记录对比 → 不符则按系统实际重写**。

**2. 对比口径 + 批注规范格式（2026-09-02 用户确认，以鲁德刚 AC 批注为范本）**
- 班课批注写成**按年级分段的明细**，不用一段话说明，也不用压缩式 `年级X人×N节`：
```

4人  1

- 格式规则：
  - 每个年级单独一行（用规范年级名：七八九年级系，不用"8年级/9年级"）
  - 年级下面每行一个档位：`N人  次数`（人数从小到大排），不加"次/班/节"后缀

  - 首行可保留原录入人前缀（如"澄澄:"）；AI 重写用作者 `排课记录`
- 统计来源：**系统排课记录**的（年级,实到）计数，不用老师自报的
- 衔接班归在读年级（七升八→七年级、初升高→九年级等），批注里不再出现"七升八"这类班名

### ⚠️ 清空单元格的坑（2026-08-04 踩过）

## 五之二、合并薪资表 续费/退费/兼职 填写（2026-09-04 定案）

### 退费填写（退费统计表"X月份"sheet 最后三列 → AN）
- 退费表最后三列：c15=教师、c16=人头、c17=业绩（负数；人头/业绩是两种扣款口径，可能只填其一）

- 每个 AN 都写批注：`老师: 学生 新签/续费 人头-50/业绩-94`（作者可标"退费表X月"）
- 合并时原理化表的 AN 值+批注会自动带过来，先核对再补缺；老师自写批注（如"徐丽萍班课人头-50"但表里无对应行）要人工确认是否补值

### 兼职老师（排课有课、薪资按节算、A列标"兼职"）

## 十四、全量检查流程总纲（2026-09-08 归纳，每月按此逐项过，防漏）

> 目的：一次把工资表全部校验项走完，**不再出现"只查班课漏 1v1"这类漏检**。每项都要输出结果（✅全对 / ⚠️名单），不能跳项。

**① 核对表差值全扫（最容易漏，先做）**
- S列(1v1差=Q-R) + V列(班课差=T-U) **全表扫非0**，输出名单交用户
- 教训：8月只盯班课 V 漏了 1v1 S → 范仙阳+18/何心-1.8/董葛飞-4.25 三处被用户发现

**② 差值溯源定位（有 I/J 列后才能做）**
- 用排课记录「上课学员/上课时间」定位具体那节课：实到0但状态已上课(请假)、代课折算、漏填节数、N-Z填错行
- 溯源口径：何心类=实到0不计；范仙阳类=初二漏10节；董葛飞类=人工折算（问用户）

**③ AE 档位校验（27位全职）**
- 期望AE = 档位(查AD) + 星级加成；**星级用5月基准/反推，不轻信F列**
- 特例：AD≤30 → AE=0；TRMT 无加成
- 产出：不符名单（8月3处人工特殊值 → 用户拍板后改）

**④ AF/AD 公式完整性**
- AD=AA+AC 公式在；AF=(AD-30)*AE（TRMT=AD*AE）；AV 总工资公式含 AF/AG/AK/AL/AM/AN/AO/AP/AQ/AR/AS/AT/AU

**⑤ 年级完整性（定级后自查）**
- 排课记录 0 无年级、0 异常年级（如8月权威版不应有"高三"残留）

**⑥ 续费/退费/兼职核对（合并表）**
- 续费：AH/AI/AJ 拆分存在，AK 公式结果 = 续费表总计(交叉验证)
- 退费：AN = 退费表最后三列(教师c15)人头+业绩之和(负数) + 批注
- 兼职：AF = 节数×单价（静态值）+ 批注；不参与 AA/AC 折算体系

**⑦ 名单完整性**
- 排课老师 vs 薪资表名单差集：确认缺的人属于语文/英语/其他组才可放过
- 管理行（李凡）AM 管理奖单独验证

**顺序**：①差值 → ②溯源 → ③AE → ④AF/AV → ⑤年级 → ⑥续退兼 → ⑦名单。**每项输出结果再进下一项**。
