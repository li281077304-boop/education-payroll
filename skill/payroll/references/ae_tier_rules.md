# AE 档位 + 星级加成规则（课时单价核算）

> ⏳ **有效期至 2026 年 9 月**，10 月可能调整。规则由用户口头确认，脚本 `verify_ae_af.py` 内置同一套数值。

## 一、AE（该档每小时金额）计算式

```
AE = 基础档位(查 AD 列) + 星级加成(查 F 列教师级别)
```

- AD 列 = 最终授课小时数据
- F 列 = 教师级别（含「几星」，TR/TRS/TRST/TRMT 为前缀，不影响星级判定）

## 二、基础档位表（AD → 基础金额）

| AD 范围 | 基础金额 |
|---------|---------|
| 0 – 30  | 0       |
| 31 – 60 | 30      |
| 61 – 80 | 32      |
| 81 – 100| 34      |
| 101 –130| 36      |
| 131 –160| 37      |
| 160 以上| 38      |

> 规律：0–30 档基础金额为 0（前 30 小时不计课时费，见 AF 规则）。

## 三、星级加成

| 星级 | 加成 |
|------|------|
| 一星 / 二星 | +0 |
| 三星 | +5 |
| 四星 | +10 |
| 五星 | +15 |
| 六星 | +20 |

**教师级别提取**：F 列含「几星」即取对应星级；`TR`/`TRS`/`TRST`/`TRMT` 等前缀不计入星级判定。

## 四、AF（总课时费）公式规则

- 普通老师：`=(AD-30)*AE` —— 前 30 小时不计入课时费
- TRMT 老师：`=AD*AE` —— 全额计入，无减免
- 规律：非 TRMT 都减 30，TRMT 不减

## 五、薪资表关键列对照

| 列 | 含义 |
|----|------|
| C  | 姓名 |
| F  | 教师级别（含星级） |
| AD | 最终授课小时数据 |
| AE | 该档每小时金额 |
| AF | 总课时费 |

## 六、管理 / 底薪类行

管理岗（如「基本工资 6000 + 管理团队奖」）不在 AE 课时费规则覆盖范围内，
用 `verify_ae_af.py --skip-keywords 管理,底薪` 跳过核对。
