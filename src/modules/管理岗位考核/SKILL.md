# 管理岗位考核表制作

从模板复制生成当月考核表，并按统一口径填入数学组/理化组的 进步率、周平均、续费人次率、退费人次率、离职率，得分由模板公式自动计算。

## 〇、每月原材料（开工前核对齐全）

| # | 文件 | 用途 |
|---|------|------|
| 1 | **上月考核表**（如 `二校管理岗位考核表数学&理化-2026年6月.xlsx`） | 当月模板 + 进步率沿用 |
| 2 | **数学/理化数据统计表**（`数学组数据统计表-宣城二校X月第X周.xls`、`理化数据统计表xlsx(N).xlsx`） | 周平均（组课时生产页）、总学员数（学生页） |
| 3 | **续费+推荐数据**（`2026年度续费+推荐数据(1).xlsx`） | 续推人次 |
| 4 | **退费统计表**（`副本宣城二校退费统计表2026年.xls`） | 退费人次 |

⚠️ 缺文件先问用户，不硬填。

## 一、包结构

```
管理岗位考核/
├── SKILL.md                        ← 本文档
```

运行环境：Python 3.9+，需 `pandas` / `openpyxl` / `xlrd`（系统 `/usr/bin/python3` 已具备）。

## 二、模板与复制

- 复制上月考核表为当月文件：`二校管理岗位考核表数学&理化-2026年X月.xlsx`
- 模板结构：sheet `月度最佳学科组考核`（数学组行8、理化组行10，宣城二校）、`月度最佳教学部考核`、`月度最佳客服部考核`、`月度最佳咨询部` 等
- 本月只填「月度最佳学科组考核」页的 数学/理化 两行（其他 sheet 空着不动）

## 三、指标口径（用户确认 2026-08-05，勿自行发明）

| 列 | 指标 | 口径 | 来源 |
|----|------|------|------|
| D | 进步率 | **维持上月值**（无成绩数据时） | 上月考核表 |
| F | 周平均（一对一） | **组课时生产页「一对一 月周均」（K列，月总行）** | 数学/理化数据统计表 |
| H | 续费人次率 | 续推人次 ÷ 总学员数 | 续推表 + 学生页 |
| J | 退费人次率 | 退费人次 ÷ 总学员数 | 退费统计表 + 学生页 |
| L | 离职率 | 0 | — |

7月参考值（已核实）：进步率 数学0.7073/理化0.8611；周平均 数学5.78/理化5.9；续推人次 数学46/理化34；退费人次 数学9/理化2；总学员 数学365.8/理化200.4。

### ⚠️ 续推人次（最容易数错的坑）

- 口径：**续推表当月 sheet 里，1V1 每周列（4-8，5周）+ 班课每周列（10-18，9周）中每个非0数字 = 1人次**
- ❌ 不是"有数据的老师人数"（我踩过：数出15/8，正确是46/34）
- 7月分解：数学 1V1周人次14 + 班课周人次32 = **46**；理化 11 + 23 = **34**

### ⚠️ 退费人次

- 口径：**退费统计表当月 sheet 的 P列（"批注"列，0-based col 15，内容=负责教师姓名）非空记录数 = 退费人次**
- ❌ 不是学生页的"退费列"累计（我踩过：数学数出14，正确是9）
- 7月总数11：数学9（徐良琴/李梦×2/梁缘×2/周文婧/廖永翠/张昱/王星）、理化2（潘政豪/何心）
- 注意：王星已删行但退费条在她名下，是否算入数学组需用户确认（默认算）

### 总学员数（分母）

- 学科组数据统计表「学生」sheet 单科数月均：7月 数学365.8 / 理化200.4

## 四、得分公式（模板自带，不手动算）

| 列 | 得分项 | 公式 | 满分 |
|----|--------|------|------|
| E | 进步率 | `=D/0.8*30` | 30 |
| G | 周平均 | `=F/3.8*25`（基数3.8） | 25 |
| I | 续费 | `=H/0.08*25`（目标8%） | 25 |
| K | 退费 | 分段IF（≤1%满分10，≥3%为0） | 10 |
| M | 离职 | IF（≤4%满分10） | 10 |
| C | 总分 | `=E+G+I+K+M` | 100 |

## 五、写入方法

- 备份先行：`cp 原文件 原文件_备份(改动前).xlsx`
- 周平均写**数值**（5.78 / 5.9）；续费/退费写**公式**（`=46/365.8`、`=9/365.8`），透明可查
- `wb.calculation.fullCalcOnLoad = True`，保存后得分自动重算
- 退费表是 .xls：用 `xlrd.open_workbook(f, formatting_info=True)` 读
- ⚠️ 文件被 WPS/预览打开时会锁文件/回写旧缓存：改完立即二次验证，交付前检查 `lsof` 无写锁；提示用户关旧版重开

## 六、脚本用法

```bash
/usr/bin/python3 scripts/compute_kh_metrics.py \
  --month 7 \
  --folder "/Users/macos/Desktop/7月工资表制作与核查" \
  --math-stat "数学组数据统计表-宣城二校7月第5周.xls" \
  --phy-stat "理化数据统计表xlsx(4).xlsx" \
  --xutui "2026年度续费+推荐数据(1).xlsx" \
  --tuifei "副本宣城二校退费统计表2026年.xls"
```

输出：周平均（组课时生产K列）、续推人次（46/34口径）、退费人次（P列口径）及按教师拆分清单。

## 七、校验清单（填写后核对）

- [ ] 周平均 = 组课时生产「一对一 月周均」K列（不是自己算的课时÷生数）
- [ ] 续推人次 = 1V1周列+班课周列 非0单元格数
- [ ] 退费人次 = 退费表P列非空记录数，且按组分（数学/理化）合计=总数
- [ ] 分母总学员数正确（学生sheet单科数）
- [ ] 进步率沿用上月；离职率0
- [ ] 公式 `=46/365.8` 类已写、fullCalcOnLoad 已设、备份已留
